# coatless-dashboard.github.io

Auto-built project index for [coatless-dashboard](https://github.com/coatless-dashboard), deployed to
[dashboard.thecoatlessprofessor.com](https://dashboard.thecoatlessprofessor.com/).

Source: [coatless/quarto-org-index](https://github.com/coatless/quarto-org-index).

Rebuilt daily by GitHub Actions plus on push to `main` and on
`repository_dispatch` event `refresh`.
